00 / READING THIS PAGE

Factory keys, by menu.

Each menu lists its commands that have a key. A dash means no key on that platform: a browser keeps some keys for itself, such as Ctrl+N, Ctrl+W and Ctrl+0, so there RSpice uses another key or none. Every command is still in its menu and in the command palette, Ctrl+K.

A key acts only where its Acts in column says, and the same key can mean one thing on a schematic and another in a symbol view or a source editor. Keys whose Acts in names a view or a workspace do nothing while you type in a text field. Single letters such as W or R act while the drawing has keyboard focus; Preferences › Shortcuts can require Alt with them or turn them off, and can change any key here.

On a Mac, RSpice writes Ctrl as ⌘ (Command), Alt as ⌥ (Option) and Shift as ⇧; point at a key to see it so. Key names are the ones egui 0.35, the toolkit RSpice draws with, gives them.
