01 / THE RESULTS WORKSPACE

Runs, datasets and quantities.

The Results workspace (Alt+4) lists the retained runs and each run's quantities in its data browser. Results › Results browser opens that browser and Results › Waveforms the waveform view. View › Split with results (Ctrl+\) shows results beside the design, so you can probe and read in one place.

From a dataset, the command palette's Open producing simulation plan goes back to the plan and analysis that produced it. Results › Clear result history clears the result history and the views built on it; it is unavailable while a run is executing.

03 / RESULT DOCUMENTS

Quick views, and documents that keep their work.

Opening a run shows it in a quick view: what you add there can be read but is not kept. Results › New result document… makes a project result document instead, which keeps its panes, measurements and comparisons with the project. Add pane… adds a plot pane to it, and Plot properties… edits the plot.

04 / CURSORS AND MEASUREMENTS

Read values off the data.

  • Link A/B cursors (Shift+C) shares the A and B cursor positions across the panes; a result document keeps the link through a save. Simulate › Annotate transient voltages writes the voltages at cursor A onto the schematic.
  • Add measurement… evaluates a scalar expression on the selected pane's analysis. In a result document the measurement is kept; in a quick view you can read it, but it is not kept.
  • Calculator… opens the waveform calculator as a floating tool that stays open while you work in the plot.
  • Expression diagnostics… lists every saved expression, across every analysis of the active dataset, with whether it evaluated, so a broken one shows up even on a sheet nobody has opened.

05 / COMPARE AND SLICE

Against a baseline, across a family.

Compare datasets… compares the result you are looking at with a baseline dataset. In a result document the comparison is recorded with both datasets; in a quick view it is shown and not kept. Family slicing and pivot… slices, pivots, encodes and filters a sweep, corner or Monte Carlo family. For yield, corners and regression verdicts, see Verification.

06 / IMPORT AND EXPORT

Datasets in and out.

COMMANDFORMATS
File › Import › Result dataset…RSpice result and dataset files (.rspiceresult, .rspicedata), CSV, TSV, Touchstone (.s1p to .s4p, .snp, .ts), HDF5, Arrow and Feather, Parquet, NumPy (.npy, .npz), MATLAB (.mat), SPICE raw, PSF ASCII, VCD and FST.
File › Export › Dataset…RSpice result bundle, RSpice dataset bundle, CSV, TSV, Touchstone v2, HDF5, NumPy .npy and .npz, MATLAB v5 and VCD.
File › Export › Image or PDF…PDF, PDF/A, SVG, PNG or TIFF of the active view (Ctrl+Alt+Shift+E).

An imported dataset becomes a retained run marked as external data: it never claims to be an RSpice solve of the project. Results › Report editor… lays out report pages, with results inserted, for printing and export.
