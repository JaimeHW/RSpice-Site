0.1.0 / 2026-11-01

0.1.0, the development build of 1 November 2026.

0.1.0 is the version the RSpice source declares. There is no signed installer for it: build it from source. This entry lists what a user of the desktop application sees changed between 20 October and 1 November 2026, on RSpice main up to commit c72435a76c. Smaller fixes are in the commit history.

The menu bar has ten menus.

File, Edit, View, Design, Simulate, Results, Verify, Tools, Window and Help. Each menu now holds one kind of work:

  • File makes, opens, closes, saves, imports, exports and prints. Open recent lists the recent files, newest first, and ends in All projects. Import and Export are submenus; Exit is on Windows and Linux only.
  • Edit holds every edit to the selection, including Move, Stretch, Create array, Replace instance and Bulk edit, which were in Design. Undo and Redo name the step they take, such as “Undo place resistor”.
  • View holds the zooms, a Grid submenu, Display options and the panels (Navigator, Inspector, Console, Split with results, Problems), which were in Window.
  • Design moves through the hierarchy, then has Place, Arrange and Sheet submenus, design management, and the checks. With a symbol in front, Place lists the symbol's drawing tools.
  • Simulate manages plans, sets them up through a Setup submenu of the nine setup pages, checks, runs and stops, then reads the operating point back onto the schematic.
  • Results opens the Results browser and the viewers; View as offers only the viewers the selected result can be read in.
  • Verify lists Monte Carlo yield, Process corners, Parameter tuning, Optimization, Safe operating area, Specification matrix and Regression.
  • Tools replaces the Models and Automation menus: the Library manager, the model tools, PDK and model paths, the Netlist and script editor and Scripts.
  • Window moves documents between windows, reaches all eight workspaces (Alt+1 to Alt+8) and lays out panels.
  • Help has RSpice Help, Keyboard shortcuts, Examples, Release notes, Report a problem, License and activation, and the notices.

The command palette's tabs follow the ten menus, and each command in it names where the menu bar has it, such as “Design › Place”.

New commands.

  • Edit › Select › Instances, Wires, Net labels, Pins, Text or Shapes replaces the selection with every object of that kind on the active schematic sheet. Edit › Deselect all clears it.
  • Edit › Copy as image puts a picture of the selection, or of the whole view, on the clipboard: the export's drawing, not a screenshot.
  • View › Zoom previous (Shift+W) steps a schematic or symbol canvas back through up to 16 earlier views.
  • View › Grid › Dots, Lines or Off draws one grid style; G still steps through them.
  • Design › Highlight net lights the net the selection is on, as clicking a wire does.
  • Design › Create symbol from schematic, Variants and Annotate reference designators open those tasks directly.
  • Simulate › Annotate DC operating point and Annotate transient voltages label the schematic's nets with the operating point, or with the transient's values at results cursor A.
  • File › Print reaches system printers on macOS and Linux through CUPS. It was a Windows feature.
  • Menu access keys on the Windows and Linux desktop: Alt and a menu's underlined letter opens it, a tap of Alt moves the focus to the menu bar, and a row's letter chooses it.
  • The RSpice menu on macOS holds About RSpice, Settings (⌘,) and Quit RSpice (⌘Q); Window begins with Minimize and Zoom, and keys are written with the macOS symbols.
  • Help › Examples opens one of six demonstration circuits, such as an RC low-pass filter or a CMOS inverter, as a new project.
  • Help › Report a problem is the command once called System diagnostics and log locations.

Removed.

  • The Specialist tool browser and the 34 preview workspaces it listed but could not open, and the PDK technology administrator, which only that browser reached. Tools › PDK and model paths stays.
  • Source navigation and language tools, a nine-tab dialog. Rename symbol (F2), Go to definition and Find references (F12 and Shift+F12 on the desktop) and Format document act directly in the source editor.
  • HSPICE and Xyce netlist export, which wrote the SPICE netlist under another extension. File › Export offers SPICE and Spectre netlists.
  • Export schematic SVG (File › Export › Image or PDF writes SVG too) and Export publication snapshot.
  • Reset active view. The zooms, Fit and each filter's own clear button restore what is shown.
  • The Migration guide in the Help Center. Its notes are below.
  • Recent projects (File › Open recent lists the projects) and Custom sheet sizes (Sheet defaults offers the size library).

Moving from an earlier build.

  • Projects: a project saved by an earlier build is brought up to date when it opens; there is no separate migration step. Keep a copy of the project and of the model and source files it refers to before opening it in a newer build, and run Design › Check design and Simulate › Check and netlist before saving over it.
  • Keyboard shortcut profiles keep loading. A key bound to a removed command is dropped without a warning, and a key bound to a few renamed commands, such as the old Run checks, reaches the command that replaced it.
  • Netlist export: a saved HSPICE or Xyce export format reads back as SPICE.
  • Sessions: a session left on a removed workspace opens on Design.
KNOWN LIMITSResult plots keep no Zoom previous history yet. In a browser, Copy as image needs a secure page. Annotate transient voltages draws nothing for a stepped transient. The printer driver properties button is Windows only.

RELEASE REQUIREMENTS

Required contents of a public release.

  • Pin a revision: identify the exact source commit, dependencies, toolchain, model bundle, and platform target.
  • Run the gate: retain unit, integration, corpus, and host smoke-test artifacts for the release revision.
  • Ship a signed artifact: publish installer provenance, checksums, support window, known limitations, and rollback path.
  • Publish release notes: list user-visible changes, fixed defects, known limitations, migrations, and compatibility changes.
