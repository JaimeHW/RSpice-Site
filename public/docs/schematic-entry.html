01 / THE DESIGN WORKSPACE

The drawing, the navigator and the shelf.

The Design workspace (Alt+2) shows the open cell view: a schematic, a symbol, or a Verilog-A source. Its side panel has two tabs: Navigator, for the design in front of you, and Component shelf, for the parts you can add to it.

Single-letter keys such as W or R act while the drawing has keyboard focus, and not while you type in a field. Preferences › Shortcuts can require Alt with them, turn them off, or change any key. The keys below are the same on the desktop and in the browser unless the text says otherwise.

02 / PLACE PARTS

From the shelf or the Place menu.

In the Component shelf, click a part to arm it, or drag it onto the sheet. The built-in parts are grouped as Passives, Sources, Analog, and Mixed signal / XSPICE. Design › Place arms the common parts and drawing objects by key, and Place › Instance… (Shift+I) places a cell from a library.

Edit › Paste (Ctrl+V) and Edit › Duplicate (Ctrl+D) float the copy under the pointer until you click to place it: R rotates it, M mirrors it and Escape lets it go. Edit › Repeat last command (.) runs the last placement or editing command again, as it last ran.

04 / EDIT AND ARRANGE

Select, change and line up.

  • Move (M) moves the selection; Stretch (S) moves a selected wire segment, or a shape's control point, and the wires joined to it follow.
  • Properties… (Q) edits the selected object's values; Rename… (F2) renames it.
  • Design › Arrange: Rotate clockwise (Ctrl+R), Rotate counter-clockwise (Ctrl+Shift+R), Mirror about vertical axis (Ctrl+M), Mirror about horizontal axis (Ctrl+Shift+M), the Align and Distribute commands, and Snap selection to grid.
  • Edit › Select selects every Instance, Wire, Net label, Pin, Text or Shape on the active sheet. Edit › Find… (Ctrl+F) searches the design; Find and replace… (Ctrl+H) has that key on the desktop only.
  • Replace instance…, Create array… and Bulk edit… in the Edit menu change many objects in one step. Design › Annotate reference designators… assigns reference designators, and Design › Object table… (Ctrl+Shift+T, desktop) lists objects in a table.

06 / HIERARCHY AND SYMBOLS

Cells inside cells.

  • Design › Descend (Shift+E) opens the selected instance's cell, following your edit-in-place preference. Descend with options… (H) lets you choose the edit mode: edit in place, open an isolated cell view, open a read-only reference, or edit its symbol in place. Return to parent (Shift+H) goes back up.
  • Create symbol from schematic… makes a symbol for the open schematic's cell from its pins, so the cell can be placed as an instance elsewhere.
  • Create hierarchy… turns the selection into a new child cell with a generated symbol.
  • Edit symbol in place edits the selected instance's symbol where it stands on its parent schematic; in the symbol view, Return to parent schematic (Enter) goes back.
  • In a symbol view the Place menu holds drawing tools instead: Pin (P), Line (L), Rectangle (R), Circle (C), Arc (A), Polygon (G) and Text (T). Validate and save symbol checks the symbol's pins against the cell's interface and saves it.

07 / SHEETS

Multi-sheet schematics.

Design › Sheet moves between sheets with Previous sheet (PageUp) and Next sheet (PageDown), adds one with New sheet, and removes one with Delete…. Sheet properties (Ctrl+Alt+Shift+P) shows the open sheet's properties in the inspector; Sheet formats… and Sheet defaults… manage the formats and the defaults new sheets take.

09 / PRINT AND EXPORT

Get the drawing out.

File › Print… (Ctrl+P; Ctrl+Alt+P in the browser) prints the active view. File › Export › Image or PDF… (Ctrl+Alt+Shift+E) writes it as PDF, PDF/A, SVG, PNG or TIFF. Edit › Copy as image puts the selection, or the whole view, on the clipboard as a picture. To simulate the circuit, go on to Simulation setup.
