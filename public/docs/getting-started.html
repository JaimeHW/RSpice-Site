01 / RUN RSPICE

Build the desktop application, or open the browser build.

Signed installers are not published yet, so the desktop application is built from source. With Rust installed (the repository pins the version it needs), from a checkout:

The docs index has the command-line build too. The browser build is the same application compiled to WebAssembly. It is experimental and needs a browser with WebGPU. A browser keeps some keys for itself, so RSpice uses others there: Run is Ctrl+Enter rather than F5, and Save is Ctrl+Alt+S rather than Ctrl+S. Keyboard shortcuts lists both sets.

02 / THE START SCREEN

With no project open.

RSpice opens on a screen headed No project open, with four ways in. The same commands are in the File menu.

ACTIONWHAT IT OPENS
New projectA new project with a blank top cell. You name the project, its design library and the top cell.
Open project…A saved project, a .rspiceproj file. In the browser the file is imported.
Open SPICE deck…A SPICE deck as a netlist project, which has no schematic. See Netlists and scripts.
Open schematic…A single schematic cell view, a .rsch file.

Under them, Recent projects lists the projects opened on this device, most recent first, with Pinned and Shared filters and a search box. If an earlier session was interrupted, an Interrupted session card offers its recovery checkpoints for review; Troubleshooting explains them.

03 / CREATE A PROJECT

A project holds the design, its plans and its results.

  1. Choose File › New project… (Ctrl+Shift+N). The Create RSpice project dialog asks for a Project name.
  2. Library follows the name until you edit it, and Top cell starts as top. The top cell gets a schematic view, and the project gets a simulation plan and a drawing sheet.
  3. Choose Create project. Nothing is written to disk until you save.
  4. Choose File › Save (Ctrl+S). On the desktop, a project never saved before asks where its .rspiceproj file goes; in the browser it is kept in the browser's storage.

If a project with unsaved changes is open, New project asks about those changes first.

04 / OPEN AN EXAMPLE

Six ready-drawn circuits.

Help › Examples… lists six demonstration circuits. Opening one replaces the session with a new project named after the circuit, draws it as the top cell, then asks where to save it: a file you choose on the desktop, the browser's storage on the web.

EXAMPLECIRCUIT
RC Lowpass FilterR1 1k into C1 159n: a first-order low-pass with its corner at 1 kHz.
Voltage DividerTwo 10k resistors halving a 5 V supply.
Common Emitter AmplifierAn NPN stage on 12 V with base bias, collector load and emitter degeneration.
CMOS InverterA PMOS and NMOS pair on 3.3 V, switched by a pulse input.
Differential PairTwo NPN transistors sharing a 1 mA tail: an op-amp input stage.
Opamp Inverting AmplifierA gain of −10 from 10k over 1k around a high-gain op-amp.

05 / WORKSPACES

Eight workspaces, one project.

Each workspace is one kind of work on the open project. Switch with Window › Workspace or the keys below, which are the same on the desktop and in the browser.

WORKSPACEKEYFOR
ProjectAlt+1The project overview, its libraries and cells, configurations, dependencies and recovery.
DesignAlt+2Schematics, symbols and Verilog-A views: Schematic entry.
SimulateAlt+3The simulation plan and its setup pages: Simulation setup.
ResultsAlt+4Retained runs and their views: Results.
VerifyAlt+5Yield, corners, tuning, optimization, safe operating area and regression: Verification.
ModelsAlt+6Model libraries and PDKs: Models and PDKs.
Netlist and script editorAlt+7SPICE decks and Python workflows: Netlists and scripts.
Stimulus libraryAlt+8Reusable source definitions: Simulation setup.

06 / A FIRST RUN

Check, run, read.

  1. Open an example, or draw a circuit in the Design workspace.
  2. Open the Simulate workspace (Alt+3). Its Analyses page lists the plan's analyses; Simulate › Add analysis… adds one, such as Transient for waveforms over time.
  3. Choose Simulate › Run (F5; Ctrl+Enter in the browser). The plan is checked before any solving starts, and a plan that cannot run is refused with the reason. Simulate › Stop (Shift+F5; Ctrl+Shift+Enter in the browser) ends a run.
  4. Open the Results workspace (Alt+4) to read the run's waveforms and values.
